# Evidence Folder

This folder documents what evidence you should collect when you later
do the REAL Project 9 exercise with an actual Remote Claude Routine (not
this local simulation).

## Evidence Checklist for the Real Exercise

1. A screenshot of the Routine's configuration (prompt, repository,
   trigger set to one-off, not a repeating schedule).
2. Confirmation that the successful run was fired (via Run now or a
   one-off schedule).
3. The full transcript of the successful run, saved or screenshotted.
4. The text of the deliberately broken prompt (pointing at a file that
   does not exist).
5. Confirmation that the broken run was fired the same way.
6. The full transcript of the failed run, saved or screenshotted.
7. A side-by-side comparison showing both runs displayed a green
   status, even though only one task actually succeeded.
8. Your own one-sentence statement of the A5 lesson: why the status
   column alone could not tell the two runs apart.

## Why This Matters

This local simulation lets you rehearse the reasoning and the workflow
safely, offline, before spending real one-off runs on an actual cloud
Routine. When you do the real exercise, use this checklist to make sure
you have captured enough evidence to prove you actually understood the
lesson, not just that you clicked through the form.
