# Evidence Folder

This folder holds proof artifacts for the Project 10 Secrets Drill.

## What This Folder Proves

1. **.env is gitignored** - see the project's `.gitignore` file, which
   lists `.env` on its own line.

2. **Local .env exists only for rehearsal** - you create your own local
   `.env` file with your real OpenRouter key for your own personal use.
   This project never creates, reads, or stores that real value.

3. **The fresh clone does not contain .env** - see
   `fresh-clone-simulation\` below, generated by
   scripts\simulate-env-failure.ps1, and
   `transcripts\failed-env-file-run.md`, which confirms
   OPENROUTER_API_KEY = [NOT AVAILABLE] inside that simulated clone.

4. **The second run obtained the key from the environment** - see
   `transcripts\successful-environment-run.md`, which shows
   OPENROUTER_API_KEY = [AVAILABLE], sourced from a process environment
   variable, not a file.

5. **The prompt explicitly prevented .env lookup** - see
   `routine-prompt.md`, "Second Run Prompt" section, which contains the
   exact line: "credentials are available as environment variables; do
   not look for a .env file."

6. **The real secret was never exposed** - every transcript, report,
   config file, and script in this project reports the key's status as
   [AVAILABLE] or [NOT AVAILABLE] only. No real OpenRouter API key
   value ever appears anywhere in this project's files.

## fresh-clone-simulation\ Folder

When you run scripts\simulate-env-failure.ps1, it creates a
`fresh-clone-simulation\` folder here, containing a copy of this
project's non-gitignored files (specifically excluding `.env`), to
concretely demonstrate that a fresh clone never receives a gitignored
file. Inspect this folder after running the script and confirm for
yourself that no `.env` file is present inside it.
