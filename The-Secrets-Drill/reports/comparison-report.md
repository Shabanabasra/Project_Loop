## The mechanical chain

.env is gitignored
-> gitignored files do not reach GitHub
-> Routine starts from a fresh clone
-> fresh clone does not contain .env
-> secret is unavailable
-> task fails

Environment Variables panel
-> Routine receives the secret through the environment
-> prompt explicitly tells Claude not to look for .env
-> secret is available
-> task succeeds

## The Project 10 lesson (A4)

Secrets must go in the environment variables panel, never in a .env
file, because .env is gitignored and a Routine's fresh clone will never
contain it. Pairing this with an explicit prompt instruction not to
look for a .env file removes any wasted attempt down a path that could
never succeed. In both runs the real secret value was never printed -
only its availability status was reported.
