# # Transcripts Folder

This folder holds example/simulated transcripts for three independent
implementer runs and three independent reviewer runs, one pair per
labeled issue (001, 002, 003).

IMPORTANT: every transcript in this folder is SIMULATED. No real
GitHub issue, branch, pull request, or review comment was created by
generating these files. Real transcripts are produced by
scripts\simulate-implementer.ps1 and scripts\simulate-reviewer.ps1, and
would be replaced by real Routine transcripts once you connect actual
Claude Code / claude.ai Routines to a real repository.

- implementer-run-001.md / 002 / 003 - one per labeled issue
- reviewer-run-001.md / 002 / 003 - one per resulting simulated PR

Each transcript records: Run ID, timestamp, trigger, issue/PR identity,
work performed, evidence, result, and an explicit statement of role
boundaries (what this Routine did NOT do).
