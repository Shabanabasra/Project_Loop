# Transcripts Folder

This folder holds the full run transcript for the dreaming loop's
simulated weekly run.

- dreaming-run-001.md - the transcript for the one simulated run in
  this rehearsal

This file is regenerated every time you run
scripts\simulate-dreaming-loop.ps1. It is SIMULATED - no real GitHub
branch, pull request, or Routine execution is created by generating it.

The transcript is the primary evidence trail: scripts\validate-evidence.ps1
and scripts\compare-gate.ps1 both read this file (and progress.md
directly) to independently verify the dreaming loop's claims, rather
than simply trusting them.
