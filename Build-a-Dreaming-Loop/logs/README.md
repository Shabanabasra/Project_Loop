# Logs Folder

This folder holds example weekly log snapshots representing the kind
of raw output an underlying loop (Project 3's morning-brief loop, or
Project 8's daily dependency-audit loop) produces. progress.md is the
accumulated, dated version of these logs that the dreaming loop
actually reads. These week-NNN.md files are reference context only -
the dreaming loop's scripts read progress.md and dreaming-state.md,
not these files directly.

- week-001.md - covers 2026-08-11 through 2026-08-17
- week-002.md - covers 2026-08-18 through 2026-08-24
- week-003.md - covers 2026-08-25 through 2026-08-31
